# 雙埔生活即時環境與大眾運輸監控系統 (Taiwan Neighborhood Monitor)

提供新北（新埔／板橋）與桃園（青埔）雙核心生活圈之即時天氣、空氣品質、雷達回波、即時交通路網監控，以及雙埔核心 YouBike 2.0 官方即時車況動態看板。

## 官方即時資料來源

- **新北市 YouBike 2.0 即時資料**：
  - 資料集：新北市政府資料開放平台 [新北市公共自行車租賃系統(YouBike2.0)](https://data.ntpc.gov.tw/datasets/010e5b15-3823-4b20-b401-b1cf000550c5)
  - OpenAPI 規格：新北市政府交通局 OpenAPI (代碼 1130000)
- **桃園市 YouBike 2.0 即時資料**：
  - 資料集：桃園市政府資料開放平台 [桃園公共自行車即時服務資料](https://opendata.tycg.gov.tw/datalist/5ca2bfc7-9ace-4719-88ae-4034b9a5a55c)

## 生活圈站點

### 1. 雙埔核心生活圈 (新埔／板橋 ⇄ 青埔)
- **路徑**：專案根目錄 (`index.html`)
- **說明**：新北板橋與桃園青埔雙核心高鐵、機捷與微移動生活圈。

### 2. 汐止保長 ⇄ 台北車站 雙向智慧生活圈 (全新獨立站點)
- **路徑**：[`xizhi-tpe-monitor/`](xizhi-tpe-monitor/)
- **核心基地**：新北市汐止區保長里長興街二段2巷1號1樓
- **終點樞紐**：台北車站
- **功能特色**：
  - 台鐵五堵 ⇄ 台北車站雙向最速通勤班次看板（即時倒數與動態行車約 22 分鐘）
  - 微移動 YouBike 2.0 雙核心即時車況（長興街二段62號、長興橋、五堵火車站、台北車站周邊）
  - 即時交通路網 CCTV 電視牆（忠孝西路前站門戶、台北轉運站、大同路新台五路口、北門廣場等）
  - 雙核心即時氣象、基隆河水情警戒與環境部 AQI 空氣品質
  - Leaflet 雙向通勤走廊互動地圖
  - 保長里在地生活機能指南（長安派出所、保長郵局、超商、診所、五堵舊隧道）
- **啟動方式**：
  - 獨立伺服器啟動：進入 `xizhi-tpe-monitor` 目錄執行 `node server.js`，開啟 `http://localhost:3001`
  - 主伺服器訪問：啟動根目錄 `node server.js` 後訪問 `http://localhost:3000/xizhi`
  - 直接瀏覽：雙擊開啟 `xizhi-tpe-monitor/index.html` 即可免伺服器離線瀏覽

## 啟動方式

### 方法一：使用內建輕量反向代理伺服器（推薦，支援 CORS 代理與快取）
```bash
# 啟動主站 (雙埔生活圈，亦可透過 /xizhi 訪問汐止站)
node server.js

# 或單獨啟動汐止保長 ⇄ 台北車站生活圈獨立伺服器
cd xizhi-tpe-monitor && node server.js
```

### 方法二：直接以靜態檔案瀏覽
直接以現代瀏覽器開啟 `index.html` 或 `xizhi-tpe-monitor/index.html` 即可。系統內建多層備援機制，離線與直連皆可正常使用。
